# Wyrmgate

Wyrmgate is building an Identity and Access Management platform focused on governable applications, extensibility, operational clarity, and deployment flexibility.

The project is currently under active private development. Public documentation, SDKs, examples, and supported integrations may be published here as they become ready.

## Security

If you believe you have found a security issue in a Wyrmgate project, please follow the instructions in our security policy rather than opening a public issue.
